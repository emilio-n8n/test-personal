# Questions from agents

An agent that hits an ambiguity writes ONE file here, named `Q-<area>-<slug>.md`, using the template
in `docs/agents/AGENT_PROTOCOL.md`. Then it continues working under the least-damaging assumption.

**Do not stop to wait for an answer.** The orchestrator reads this directory when it next wakes and
answers into `docs/agents/answers/`.

Never edit or delete another agent's question.
